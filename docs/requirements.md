# 光仔卡牌 H5 小游戏需求文档

更新时间：2026-07-02

本文档基于《卡牌-策划案框架.pdf》和当前项目代码整理，用于后续开发排期、验收和团队沟通。

## 状态标签

| 标签 | 说明 |
| --- | --- |
| 已完成 | 当前代码已实现，能在本地环境跑通或有明确代码支撑 |
| 部分完成 | 当前代码实现了一部分，但与策划案目标仍有差距 |
| 未完成 | 当前代码尚未实现 |
| 偏离策划 | 当前代码有相关实现，但玩法或结构与策划案要求不同 |
| 当前新增 | 当前代码中已有，但策划案里不是核心要求，可作为保留或二次评估功能 |

## 18. 验收口径

核心玩法验收时，至少需要满足以下流程。当前接口验收已跑通 1-9，后续仍建议补充浏览器移动端视觉验收和自动化测试：

1. 玩家登录后拥有抽卡机会。
2. 点击开包后一次生成 4 张卡。
3. 每张卡展示临时点数 1-13。
4. 玩家必须选择 3 张才能提交。
5. 选中的 3 张结算入库或转碎片。
6. 第 4 张弃牌不入库、不转碎片。
7. 后端判断 3 张点数是否可凑 24。
8. 成功时展示公式并奖励 1 次抽卡。
9. 卡册、兑换、排行榜、分享奖励均能基于新结算数据正常更新。
10. 重复点击或并发提交同一组手牌时，只允许一次结算成功。
